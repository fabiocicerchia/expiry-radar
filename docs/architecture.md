# Architecture

One binary, four packages, one code path. `ARCHITECTURE.md` at the repository
root is the derived map — regenerated by `automap map`, never edited by hand;
this page is the part a person has to write.

## Overview

```
cmd/expiry-radar   flags, exit codes, and where the report is written
      |
      v
internal/config    one JSON file -> the set of read-only sources to run
      |
      v
internal/source    one Source per provider; every call is a List/Describe
      |
      v
internal/rank      blast radius and priority, with the reason recorded
      |
      v
internal/output    five renderers, one per file
```

## Components

| Package | One job |
|---|---|
| `cmd/expiry-radar` | Parse flags, load the config, run the collection, pick the sink, return an exit code. |
| `internal/config` | Decode `expiry-radar.json` with `DisallowUnknownFields`, validate overrides and manual items at load, and build only the sources the file asked for. |
| `internal/source` | `tls.go` (endpoint probes and the chain), `rdap.go` (registrar expiry, WHOIS fallback), `k8s.go` (TLS secrets plus their ingress context), `vault.go` (token and PKI mounts), `aws.go` (ACM, IAM keys, Secrets Manager), `manual.go` (what nothing can discover). |
| `internal/rank` | `Rank` scores each item; `blastScore` accumulates both the number and the evidence that moved it. |
| `internal/output` | `output.go` holds the format table and the dispatch; `table.go`, `json.go`, `ical.go`, `prometheus.go` and `html.go` hold one renderer each. The HTML report's markup is `report.html.tmpl`, embedded at build time. |

Sources are the extension point: a new provider implements `source.Source` and
supplies the labels `internal/rank` reads. Adding one that returns only an
expiry date makes the tool worse, not bigger.

## Data flow

1. `config.Load` reads the file and rejects anything that would silently scan
   less — an unknown key, a glob `path.Match` cannot parse, a manual item with a
   misspelled kind.
2. `config.File.Sources` constructs only the enabled sources. Nothing is enabled
   implicitly, and credentials come from the environment, never from the file.
3. `source.CollectAll` runs each source and returns items **and** errors. A
   source that fails still returns what it managed to read; the failure goes to
   stderr and the process exits 3.
4. `rank.Rank` scores and sorts. Overrides beat resource labels, which beat
   inference.
5. `output.RenderAt` renders to stdout or to the file named by `-out`. The clock
   is a parameter, not a global, so an iCal feed can be diffed in a test.

## Decisions

- **JSON, not YAML, for the config.** Keeps the config path on the standard
  library; nothing here is worth a parser dependency.
- **No `client-go`.** Two GETs against two stable, versioned Kubernetes
  endpoints do not justify that dependency tree.
- **No Vault lease enumeration.** `sys/leases/lookup` is a PUT needing `update`
  plus `sudo`, which would break the read-only promise the tool is sold on.
- **Exit codes are contract.** `0` clean, `1` a `-fail-within` threshold was
  breached, `2` bad usage or config, `3` partial results. The table is named in
  `cmd/expiry-radar/main.go` and documented in the README; the numbers do not
  move.

pile up).

## How the ranking works

`priority = 0.55 × urgency + 0.45 × blast radius`, sorted descending.

Urgency ramps linearly from 0 at ninety days out to 1 on the expiry date, and
stays at 1 once expired. It is a **weighted sum, not a product**, on purpose: a
product ranks everything beyond the horizon at exactly zero and throws away the
ordering that makes the tool worth running.

Blast radius starts from the kind (a domain or an intermediate CA outranks a
leaf certificate, because it takes out everything below it) and is then moved by
whatever evidence exists: internet-facing, production vs non-production
namespace, wildcard or multi-SAN coverage, reported traffic, and whether an ACM
certificate is in use at all. Environment detection matches whole tokens, so
`device-registry` is not "dev" and `reproduction-service` is not "prod".

Two things override inference, in order: an `expiry-radar/blast-radius` label on
the resource, then an operator `overrides` glob in the config. Inference exists
because most estates have no reliable labels — not because it knows better.

Every row carries a `WHY` column. A ranking nobody can explain gets ignored.
